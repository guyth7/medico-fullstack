---
# Medico — منصة موحّدة للسجلات الطبية

- عرض مشروع التخرج: نظام إدارة سجلات المرضى متعدد الجهات
- مؤلف: Medico codebase
---

# المشكلة

- سجلات المرضى مبعثرة بين مستشفيات ومختبرات وصيدليات
- صعوبة التعرّف السريع على هوية المريض وتفادي تضارب الوصفات

---

# الحل المقترح

- واجهة ويب موحّدة تربط الأطراف (أطباء، مستشفيات، مختبرات، صيدليات)
- قاعدة بيانات مركزيّة (Firestore) مع سياسات أذونات دورية

---

# أهم الميزات

- تسجيل/دخول متعدد الأدوار مع طلب اعتماد إداري
- بحث سريع بالاسم أو الرقم الوطني
- CRUD لسجلات المرضى مع حماية من التكرار
- إدارة subcollections للفحوصات والوصفات

---

# التقنيات الرئيسية

- Frontend: Next.js + React + Tailwind CSS
- Backend/DB: Firebase Auth + Firestore + Cloud Functions
- UI: Radix UI, Framer Motion، Sonner للتنبيهات

---

# البنية المعمارية

- بنية feature-based: `app/`, `components/`, `lib/`, `functions/`
- طبقة خدمات في `lib/` للتعامل مع Firestore وعمليات الترحيل

---

# سيناريوهات واقعية

- تبادل نتائج المختبر فورياً مع الطبيب
- تسريع استقبال المرضى عبر البحث بالهوية الوطنية
- فحص دوائي في الصيدلية بناءً على سجل المريض
